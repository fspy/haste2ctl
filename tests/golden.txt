### help
exit=0
--- stdout ---
usage: haste2ctl [-h] [--node NODE] [--wait SEC] <noun> ...

Control a HyperX Pulsefire Haste 2 (03f0:0b97): lighting, USB polling rate and DPI stages.

positional arguments:
  <noun>
    interfaces  show this mouse's hidraw nodes
    light       brightness or colour
    polling     USB polling rate
    dpi         DPI stages

options:
  -h, --help    show this help message and exit
  --node NODE   explicit /dev/hidrawN (skips auto-detection)
  --wait SEC    wait up to SEC seconds for the vendor interface to appear (for
                udev/systemd use, where enumeration races)

With no noun, every setting is reported. Brightness is volatile - it is not saved to onboard flash.
